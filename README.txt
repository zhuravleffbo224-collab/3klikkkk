3KLIK — DESKTOP DEMO WEBSITE

HOW TO OPEN
1. Extract the ZIP archive.
2. Open index.html in Chrome, Safari, Edge or Firefox.
3. Keep index.html, style.css and app.js in the same folder.

FEATURES
- Home, Explore, Create, Stats, Profile, How it works, Risks and Terms.
- Local-only demo coin creation with image upload, market, long/short, leverage and links.
- Search, sort, view coin details, and statistics.
- Browser localStorage saves coins on this browser/device. No backend or account.
- No real prices, transactions, wallet connections or payments.

ADDING YOUR COINS LATER
Send the coin list (names, tickers, descriptions, images, market data) to update the catalog. The catalog intentionally starts empty.

NOTE
The site loads Google Fonts when online; system fonts are used offline. Everything else runs locally.
